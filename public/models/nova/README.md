# Nova character model

This folder holds the rigged GLTF character used by the Nova prototype in
`src/OfficeScene.tsx` + `src/NovaCharacter.ts`.

## Current content: labelled placeholder

`nova.glb` here is a **static placeholder figure generated by
`scripts/make-nova-placeholder.mjs`**. It is original, license-free geometry
written by this repository itself. It has **no skeleton and no animation
clips**, so with it in place Nova simply stands still and looks close to the
procedural figure while the real GLB loading path is exercised. It exists only
so the loader, floor fit, bubble anchor, and fallback wiring can be validated
before an approved character asset arrives.

## Replacing it with a real rigged character

Drop a rigged GLB at exactly this path (it replaces the placeholder):

```
public/models/nova/nova.glb
```

Requirements and recommendations:

- glTF 2.0 binary (.glb), single scene, character standing at the origin,
  facing +Z, feet at y = 0 (the loader re-scales and re-grounds anyway; see
  `NOVA_TARGET_HEIGHT` in `src/NovaCharacter.ts`).
- Prefer **embedded animation clips in the one GLB**. Separate clip files
  (e.g. `idle.glb`, `walk.glb`) are NOT wired up in this milestone.
- Clip names are normalized through `src/nova-animation.ts`; recognized
  conventions include `idle`, `walk`, `work`/`typing`, `review`/`reading`,
  plus common variants (e.g. Mixamo exports, `Armature|idle`). Anything
  unrecognized falls back safely to `idle`.
- Keep the file lightweight (a few MB or less) and use permitted textures.

## Licensing

- The placeholder itself is generated by this repository and carries no
  third-party restrictions.
- Any replacement asset **must have documented redistribution terms** (e.g. CC0
  or a license that permits repo redistribution and app use). Record the
  source, author, and license in this README and in `README.md` before
  committing the asset. Do not commit assets with unclear terms.

The model URL can be overridden without code changes via
`VITE_NOVA_MODEL_URL` (see `src/NovaCharacter.ts`).
